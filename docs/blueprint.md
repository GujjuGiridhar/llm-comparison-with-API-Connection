# **App Name**: LLM Showdown

## Core Features:

- Response Comparison: Side-by-side display of LLM responses to a given prompt.
- Prompt Input: Simple form to take a prompt and display the responses.
- AI-Powered Quality Rater: Use an LLM as a tool to rate the responses from other LLMs based on criteria such as accuracy and helpfulness.

## Style Guidelines:

- Primary color: Neutral grays for a clean, analytical feel.
- Secondary color: Soft blues to convey trust and intelligence.
- Accent: Teal (#008080) for interactive elements and highlights.
- Clear, side-by-side layout for easy comparison of LLM outputs.
- Simple, geometric icons for clarity.
- Subtle transitions when displaying and comparing results.
